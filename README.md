# Viber Videos

Μικρή διαχειριστική εφαρμογή για δημιουργία δημόσιων media σελίδων με ξεχωριστό URL για κάθε φωτογραφία ή βίντεο.

## Άνοιγμα

Η εφαρμογή είναι στατική. Μπορείς να την ανοίξεις απευθείας από το `index.html` ή να τρέξεις έναν απλό τοπικό server:

```bash
python3 -m http.server 4173
```

Μετά άνοιξε:

```text
http://localhost:4173
```

## Τι κάνει

- Δημιουργεί ξεχωριστή σελίδα για κάθε φωτογραφία ή βίντεο που ανεβάζεις.
- Αν ανεβάσεις 10 αρχεία, θα δημιουργηθούν 10 URLs.
- Εμφανίζει το URL στον πίνακα και δίνει κουμπί copy για κάθε σελίδα.
- Δέχεται φωτογραφίες μόνο σε `png`, `jpg`, `jpeg`.
- Δέχεται βίντεο μόνο σε `mp4`, `3gp`, έως `200 MB` και έως `600.00 sec`.
- Εμφανίζει τη διάρκεια κάθε βίντεο σε δευτερόλεπτα.
- Υποστηρίζει προαιρετικό τίτλο/πρόθεμα, περιγραφή, slug URL και ορατότητα.
- Ανεβάζει φωτογραφίες ή βίντεο από τον υπολογιστή.
- Αποθηκεύει τα metadata στο `localStorage` και τα αρχεία στο `IndexedDB` του browser.
- Παράγει δημόσια links της μορφής `#/p/to-slug-sou`.
- Επιτρέπει αντιγραφή link, προεπισκόπηση, επεξεργασία και διαγραφή.

Σημείωση: επειδή δεν υπάρχει backend, τα uploaded αρχεία μένουν τοπικά στον συγκεκριμένο browser/υπολογιστή.
