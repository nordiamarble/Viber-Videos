# Viber Videos

Μικρή διαχειριστική εφαρμογή για δημιουργία δημόσιων media σελίδων με ξεχωριστό URL για κάθε ζευγάρι βίντεο και thumbnail.

## Άνοιγμα

Η εφαρμογή είναι στατική. Μπορείς να την ανοίξεις απευθείας από το `index.html` ή να τρέξεις έναν απλό τοπικό server:

```bash
python3 -m http.server 4173
```

Μετά άνοιξε:

```text
http://localhost:4173
```

## Τι κάνει

- Δημιουργεί ξεχωριστή σελίδα για κάθε ζευγάρι `1 βίντεο + 1 thumbnail`.
- Αν ανεβάσεις 10 βίντεο και 10 thumbnails, θα δημιουργηθούν 10 URLs.
- Εμφανίζει το URL στον πίνακα και δίνει κουμπί copy για κάθε σελίδα.
- Δέχεται φωτογραφίες μόνο σε `png`, `jpg`, `jpeg`.
- Δέχεται βίντεο μόνο σε `mp4`, `3gp`, έως `600.00 sec`.
- Για αποθήκευση σε κανονικό GitHub repository, κάθε αρχείο πρέπει να είναι έως `100 MB`.
- Εμφανίζει τη διάρκεια κάθε βίντεο σε δευτερόλεπτα.
- Χρησιμοποιεί τη φωτογραφία ως thumbnail/poster του βίντεο.
- Επιτρέπει βασική επεξεργασία thumbnail πριν το upload: crop/zoom, μετακίνηση, κείμενο επάνω και μικρό λογότυπο/label.
- Η δεξιά προεπισκόπηση ανοίγει και κλείνει από το μικρό δεξί κουμπί για να αφήνει περισσότερο χώρο στον πίνακα.
- Υποστηρίζει προαιρετικό τίτλο/πρόθεμα, περιγραφή, slug URL και ορατότητα.
- Ανεβάζει φωτογραφίες ή βίντεο από τον υπολογιστή στο GitHub repository που θα ορίσεις.
- Ενημερώνει το `data/pages.json` στο GitHub ώστε οι δημόσιες σελίδες να βρίσκουν τα media.
- Κρατά τις GitHub ρυθμίσεις τοπικά στο `localStorage` του browser.
- Παράγει δημόσια links της μορφής `#/p/to-slug-sou`.
- Επιτρέπει αντιγραφή link, προεπισκόπηση, επεξεργασία και διαγραφή.

## Ρυθμίσεις GitHub

Από το κουμπί ρυθμίσεων επάνω δεξιά συμπλήρωσε μία φορά:

- `Owner`: το GitHub username ή organization.
- `Repo`: το repository name.
- `Branch`: συνήθως `main`.
- `Media folder`: π.χ. `media`.
- `GitHub Pages URL`: π.χ. `https://username.github.io/repo/`.
- `Fine-grained token`: token με δικαίωμα `Contents: Read and write` μόνο για αυτό το repo.

Σημαντικό: το token δεν γράφεται στο repo. Μένει μόνο στον browser σου και χρησιμοποιείται για upload μέσω GitHub API.
